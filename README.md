# context-interviewer

IIS coursework project: a context interviewer that reads a folder of materials, builds a live problem model, and decides when to act, ask or wait before an agent works on a task.

## Use of AI

AI assistance (Claude, via Claude Code) is used in this project for design discussion and drafting. The author makes the decisions. [docs/decisions.md](docs/decisions.md) records each decision with its date, what the AI recommended, what the author decided in his own words, and which parts were original and which were AI-assisted. The log file itself was drafted with AI assistance from the author's verbatim messages.
