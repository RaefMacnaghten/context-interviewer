# Contributing to quillnote

Thanks for helping!

## Setting up

    git clone https://code.example.org/quillnote/quillnote.git
    cd quillnote
    python -m venv .venv && . .venv/bin/activate
    pip install -e ".[dev]"

## Running the tests

    pytest

The test suite is small and runs in a few seconds. Please run it before you open a
pull request.

## Code style

We use the default settings of the project's formatter and linter. Keep functions
short and add a docstring to anything public.

## Pull requests

Open a pull request against `main`. Link the issue it relates to in the description.
A maintainer will review it, usually within a week or two.

## Code of conduct

Be kind and assume good faith.
